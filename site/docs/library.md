## Your Library

On first start, you'll be asked to select a location for your music. This folder must be empty, and Kithsong will put any files it does not recognise into the recycle bin or trash if it finds them later. Your library folder is managed by the application and it'll keep it clean. 

### Playlists and Album Groups

Playlists are stored in the library database and can be edited on all platforms, and sync two way between them. Manual playlists work like they work in any music app - a linear list of tracks, you can add, remove, re-order. Album groups are like playlists but for albums.

Smart Playlists (and Smart Album Groups) are generated by Kithsong based on rules you provide - `last played 30d ago`, `genre=jazz`, `added last 7 days`

## Importing Music

You can import music from a folder or a zip file, on desktop and mobile. Point Kithsong at your music and it'll scan it and search MusicBrainz for releases that match. Matches that are mostly or exactly correct will be accepted automatically without input and added to the library. However, the importer may ask you to review releases where a MusicBrainz release wasn't found or is significantly different. 

Once imported, music is **copied** into your library folder and automatically filed into an appropriate file structure. Your library is always kept together. The folder you choose on start-up also contains the library database.
